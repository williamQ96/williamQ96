# William Qiu

**PhD student & researcher · University of Oregon**  
Plale Lab · NSF ICICLE AI Institute

I build intelligent systems that can be inspected. My work brings together trustworthy AI, cybersecurity, reproducible infrastructure, and human-centered computing.

[Website & research](https://williamq96.github.io/) · [Email](mailto:williamq@uoregon.edu) · [LinkedIn](https://www.linkedin.com/in/williamq96/)

## Research interests

- **Trustworthy AI:** privacy, fairness, memorization, and evidence-based model evaluation.
- **Accountable systems:** identity, provenance, delegation, and human oversight for agents.
- **Reproducible infrastructure:** scientific data, structured knowledge, open science, and developer tools.
- **Human-centered computing:** language, cognition, interaction, and interpretation.

## Selected public work

| Project | Focus |
| --- | --- |
| [FairBench](https://github.com/williamQ96/FairBench) | A synthetic prototype for auditing group-wise privacy exposure in LLM memorization, with matched controls and conservative evaluation boundaries. |
| [High-Fidelity Schema Study](https://github.com/williamQ96/high_fidelity_schema_study) | Deterministic-first schema extraction for scientific data, with recorded evidence, provenance, and structured abstentions. |
| [PATRA](https://github.com/Plale-Lab/patra-toolkit) | Collaborative research infrastructure for accountable AI/ML model lifecycles and model-card workflows with Plale Lab and NSF ICICLE. |
| [LLM-DDOS](https://github.com/williamQ96/LLM-DDOS) | A research simulation of LLM-agent coordination in distributed systems for security and threat-modeling experiments. |
| [ProtoLingua-RL](https://github.com/williamQ96/ProtoLingua-RL) | An emergent-communication experiment in which speaker–listener agents learn to coordinate through reinforcement learning and backchannel feedback. |
| [Campus Dash: UO](https://github.com/williamQ96/uocampusdash) | A Unity parkour game exploring campus navigation, interaction, timed quests, and progression. |

Project repositories document their scope and current status. FairBench is an implemented privacy-auditing prototype; its broader benchmark-suite design remains in development.
